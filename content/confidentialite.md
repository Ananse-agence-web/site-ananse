Chez Ananse, nous collectons le moins de données possible. Voici exactement ce qui se passe quand vous visitez ce site.

## Aucun cookie, aucun traceur

Ce site ne dépose **aucun cookie**, n'utilise **aucun outil de statistiques**, aucun pixel publicitaire et aucune police ou ressource chargée depuis un service tiers. C'est pourquoi vous n'avez vu aucun bandeau de consentement.

## Hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc.). Comme tout hébergeur, GitHub peut enregistrer l'adresse IP des visiteurs dans ses journaux techniques, pour des raisons de sécurité. Ananse n'a pas accès à ces journaux.

## Quand vous nous contactez

Si vous nous écrivez par e-mail ou via le formulaire de contact, nous recevons les informations que vous nous transmettez (nom, adresse e-mail, message).

- **Finalité** : vous répondre et, le cas échéant, établir un devis.
- **Base légale** : votre demande (mesures précontractuelles).
- **Durée de conservation** : 3 ans après notre dernier échange, sauf si une relation commerciale s'ensuit.
- **Destinataires** : Ananse uniquement. Nous ne vendons ni ne partageons vos données.
- **Sous-traitant** : le formulaire de contact, lorsqu'il est actif, est transmis par le service Web3Forms, qui nous relaie votre message par e-mail.

## Vos droits

Vous disposez d'un droit d'accès, de rectification, d'effacement, d'opposition et de limitation sur vos données. Pour les exercer, écrivez-nous via la section [Contact](../#contact).

Si vous estimez que vos droits ne sont pas respectés, vous pouvez adresser une réclamation à la CNIL (cnil.fr).
